# Food Security and Economic Development

**Master's Year 1 — Applied Statistics and R Programming**  
Université Paris Dauphine–PSL

**Authors:** El Ghali Debbagh and Victoria Semina

## Project overview

This collaborative academic project explores the relationships between food security and socioeconomic development indicators across countries over the period 2013–2022.

## Data sources

- [FAOSTAT — Suite of Food Security Indicators](https://www.fao.org/faostat/en/#data/FS)
- [World Bank — World Development Indicators](https://databank.worldbank.org/source/world-development-indicators)

The analysis combines nutritional, economic, educational, agricultural and health indicators.

## Data processing

- Importing and cleaning international statistical datasets.
- Harmonising country and year identifiers.
- Reshaping datasets between long and wide formats.
- Handling missing values and converting variable types.
- Merging datasets using country and year identifiers.

## Statistical methods

- Descriptive statistics.
- Cross-country comparisons.
- Statistical visualisation.
- Correlation analysis.
- Multiple linear regression.

## Technical tools

R, Quarto, dplyr, tidyr, vroom, ggplot2, Git and GitHub.

## Project scope

This project was conducted as part of an introductory Master's-level R programming and statistical analysis course. The analysis is exploratory and focuses on statistical associations rather than causal identification.

The original academic code has been retained and has not been retested in the current software environment.
